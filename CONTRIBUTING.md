# Contributing to CVD.ai

First off, thank you for considering contributing to CVD.ai! 

## Development Setup
1. Fork the repository and clone it locally.
2. Install backend dependencies via `pip install -r requirements.txt`.
3. Install frontend dependencies via `npm install`.
4. Ensure your Groq API key is set in `backend/.env`.

## Pull Request Process
1. Create a feature branch (`git checkout -b feature/AmazingFeature`).
2. Ensure any new machine learning weights are ignored via `.gitignore`.
3. Commit your changes (`git commit -m 'feat: add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request on GitHub.

Please ensure your code matches the existing style and that the React frontend builds successfully before submitting.
